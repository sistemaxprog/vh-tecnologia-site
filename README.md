# VH Tecnologia — Site institucional

## Rodar no Windows
1. Instale Node.js LTS se ainda não estiver instalado.
2. Abra esta pasta no VS Code.
3. No terminal, execute `npm install`.
4. Execute `npm run dev`.
5. Acesse http://localhost:3000.

## Personalizar
- `app/page.tsx`: textos, links e produtos.
- `app/globals.css`: cores e visual.
- Link de WhatsApp está no início de `app/page.tsx` (confirme o número antes de publicar).

## Publicação
O projeto ainda não está publicado. Para publicar, use uma hospedagem compatível com Next.js e configure seu domínio.
